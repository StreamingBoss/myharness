myharness Guide & Setup · Design preview

Understand what makes an agent work.

Start with guided experiments. Then connect your own model and explore your own tasks.

The LLM proposes. The harness supplies context, controls tools, and manages the loop.

Learn where those responsibilities meet. Experiments use the existing harness.

1. Learn through experiments

Follow a lesson, then observe the harness.

The model and the harness

Ask the model to describe a file. First disable file tools, then enable them and repeat the task.

Observe which information came from the model and which arrived through a tool supplied by the harness.

Try: Read src/greeting.py and explain what it does.

Follow this manually in the existing harness. Your model’s answer may vary.

Tools and where they run

Compare a browser workspace, a local workspace through a bridge, and a remote MCP connection such as GitHub.

A model connection supplies inference. A tool connection supplies another capability.

Instructions and memory

Change an instruction and repeat a task. Then compare a follow-up with memory enabled and disabled.

Inspect what the harness includes in each model request.

Approvals and the agent loop

Ask for a file change. Reject it once, then approve a new proposal. Observe the proposal, decision, execution result, and next model response.

Then try your own task

Use your files, a browser workspace, or the existing MCP connections. Keep the guide nearby as you experiment.
